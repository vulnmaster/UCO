## SHACL Shapes Template

Each shapes file should include:

### Required Components
1. **Node Shapes**: Class-level validation
2. **Property Shapes**: Property-level constraints  
3. **Datatype Validation**: XSD type constraints
4. **Cardinality Constraints**: Min/max count validation
5. **Value Constraints**: Enumerated value lists
6. **Cross-Reference Validation**: SPARQL-based rules
7. **Temporal Validation**: Date/time consistency
8. **Data Quality Rules**: Length, format validation

### Example Structure
```turtle
@prefix sh: <http://www.w3.org/ns/shacl#> .
@prefix icac-[domain]: <https://ontology.unifiedcyberontology.org/icac/[domain]#> .

# Node Shape for main class
icac-[domain]:[MainClass]Shape rdf:type sh:NodeShape ;
    sh:targetClass icac-[domain]:[MainClass] ;
    rdfs:label "[Main Class] Shape"@en ;
    sh:property [
        sh:path icac-[domain]:[property] ;
        sh:datatype xsd:string ;
        sh:minCount 1 ;
        sh:maxCount 1 ;
        sh:message "Property validation message."@en
    ] .

# Cross-reference validation
icac-[domain]:CrossReferenceShape rdf:type sh:NodeShape ;
    sh:sparql [
        sh:message "Cross-reference validation message."@en ;
        sh:select """SELECT $this WHERE { ... }"""
    ] .
```
